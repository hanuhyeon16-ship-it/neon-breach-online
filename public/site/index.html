THE GAME

읽기 쉽고, 깊게 싸운다.

복잡한 시스템보다 전투의 명확함을 우선합니다. 총기 역할, 이동, 스킬 효과가 한눈에 이해되면서도 팀 조합과 교전 선택에는 깊이가 생기도록 설계했습니다.

01 / MOVEMENT

빠른 전투 템포

WASD 이동과 대시를 중심으로 빠르게 진입하고 빠져나옵니다. 모든 플레이어는 자기 화면 기준으로 자기 진영이 아래에 보입니다.

02 / GUNPLAY

5개의 뚜렷한 총기

Rifle, SMG, Shotgun, Marksman, LMG가 각각 다른 연사, 반동, 탄창, 사거리와 사운드를 가집니다.

03 / TACTICS

총싸움 중심 스킬

연막, 스캔, 방벽, 오버드라이브는 총싸움을 대체하지 않고 시야와 진입 타이밍을 바꾸는 전술 도구입니다.

AGENTS

역할이 바로 보이는 4명.

캐릭터마다 하나의 시그니처 스킬만 갖습니다. 처음 플레이해도 효과를 이해할 수 있고, 숙련될수록 사용 타이밍에서 차이가 나도록 설계합니다.
